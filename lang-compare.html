⚖️ 같은 일, 다섯 가지 표현The same job, five ways to say it

언어를 비교하는 가장 좋은 방법은 같은 문제를 풀어 보는 것입니다. 이 사이트의 가상 설비 데이터로 "건전도 70 이상만 골라 정렬하고 평균 내기"를 C · C++ · Java · R · Python 으로 풀었고, 모두 같은 출력을 냅니다. 코드의 길이와 모양에서 메모리 · 타입 · 반복을 누가 챙기는지가 드러나고, 뒤에는 같은 기호가 언어마다 뜻이 다른 예와 선택 기준을 정리했습니다.

The best way to compare languages is to solve the same task. With this site's fictional asset data we solved "keep health ≥ 70, sort and average" in C, C++, Java, R and Python, and all print the same output. The length and shape of the code reveal who handles memory, types and iteration, and later come examples of one symbol meaning different things per language and selection criteria.

모든 코드는 제작 환경(gcc 13 · g++ 13 · OpenJDK 21 · R 4.3.3 · Python 3.13)에서 실제로 실행한 결과입니다. 줄 수는 빈 줄을 뺀 수입니다.

All code was really run in the authoring environment (gcc 13, g++ 13, OpenJDK 21, R 4.3.3, Python 3.13). Line counts exclude blank lines.

같은 문제를 다섯 언어로The same task in five languages

문제: 설비 5개(T1 82 · T2 64 · B1 91 · B2 58 · C1 77) 중 건전도 70 이상만 골라 건전도 내림차순으로 출력하고, 그 평균(소수 첫째 자리)을 마지막에 출력합니다. 아래 다섯 프로그램은 모두 같은 출력을 냅니다(이 페이지를 만들 때 실제로 실행해 같은지 확인했고, 테스트가 다시 확인합니다). 코드 길이와 같은 일을 어떻게 표현하는지를 비교해 보세요.

The task: from five assets (T1 82 · T2 64 · B1 91 · B2 58 · C1 77) keep those with health of 70 or more, print them in descending health, and finally print their average to one decimal. The five programs below print exactly the same output (this was checked by really running them when the page was made, and a test rechecks it). Compare the length and how each expresses the same job.

C 21 줄lines

#include <stdio.h>
#include <stdlib.h>

typedef struct { const char *id; int health; } Asset;

static int by_health_desc(const void *a, const void *b) {
    const Asset *x = a, *y = b;
    return y->health - x->health;
}

int main(void) {
    Asset assets[] = {{"T1", 82}, {"T2", 64}, {"B1", 91}, {"B2", 58}, {"C1", 77}};
    Asset good[5];
    int n = 0, sum = 0;
    for (int i = 0; i < 5; i++)
        if (assets[i].health >= 70) good[n++] = assets[i];
    qsort(good, n, sizeof good[0], by_health_desc);
    for (int i = 0; i < n; i++) {
        printf("%s %d\n", good[i].id, good[i].health);
        sum += good[i].health;
    }
    printf("avg=%.1f\n", (double)sum / n);
    return 0;
}
B1 91
T1 82
C1 77
avg=83.3

C++ 20 줄lines

#include <algorithm>
#include <cstdio>
#include <iterator>
#include <string>
#include <vector>

struct Asset { std::string id; int health; };

int main() {
    std::vector<Asset> assets = {{"T1", 82}, {"T2", 64}, {"B1", 91}, {"B2", 58}, {"C1", 77}};
    std::vector<Asset> good;
    std::copy_if(assets.begin(), assets.end(), std::back_inserter(good),
                 [](const Asset& a) { return a.health >= 70; });
    std::sort(good.begin(), good.end(),
              [](const Asset& a, const Asset& b) { return a.health > b.health; });
    int sum = 0;
    for (const auto& a : good) {
        std::printf("%s %d\n", a.id.c_str(), a.health);
        sum += a.health;
    }
    std::printf("avg=%.1f\n", static_cast<double>(sum) / good.size());
}

T1 82
C1 77
avg=83.3

Java 14 줄lines

import java.util.*;

public class Main {
    record Asset(String id, int health) {}

    public static void main(String[] args) {
        List<Asset> assets = List.of(new Asset("T1", 82), new Asset("T2", 64), new Asset("B1", 91),
                                     new Asset("B2", 58), new Asset("C1", 77));
        List<Asset> good = assets.stream()
            .filter(a -> a.health() >= 70)
            .sorted(Comparator.comparingInt(Asset::health).reversed())
            .toList();
        good.forEach(a -> System.out.println(a.id() + " " + a.health()));
        System.out.printf("avg=%.1f%n", good.stream().mapToInt(Asset::health).average().orElse(0));
    }
}
B1 91
T1 82
C1 77
avg=83.3

assets = [("T1", 82), ("T2", 64), ("B1", 91), ("B2", 58), ("C1", 77)]
good = sorted((a for a in assets if a[1] >= 70), key=lambda a: -a[1])
for name, health in good:

C 는 배열 · 반복문 · 비교 함수를 모두 직접, C++ 와 Java 는 필터 → 정렬을 표준 라이브러리로, Python · R 은 데이터 구조 자체(리스트 · 데이터프레임)가 이 일을 한 줄로 합니다. 코드가 짧은 것이 항상 좋은 것은 아니지만, 메모리 · 타입 · 반복을 직접 챙기느냐의 차이가 그대로 드러납니다.C does the array, loop and comparison function all by hand; C++ and Java do filter → sort with the standard library; Python and R let the data structure itself (list, data frame) do it in a line. Shorter is not always better, but it shows exactly the difference of whether you handle memory, types and iteration yourself.

같은 기호, 다른 뜻: 나눗셈과 나머지Same symbol, different meaning: division and remainder

다섯 줄 모두 같은 식 7 / 2 · -7 / 2 · -7 % 2를 쓰려 했지만 결과가 갈립니다. C · C++ · Java 는 정수 나눗셈이 0 쪽으로 버림(-3)이고 나머지의 부호는 앞 피연산자를 따릅니다(-1). Python 의 //는 내림(-4)이고 나머지는 뒤 피연산자의 부호(1)이며 /는 늘 실수 나눗셈(3.5)입니다. R 의 /도 실수이고 정수 나눗셈은 %/%, 나머지는 %%입니다 (아래는 Python · R 만 -7 // 2, -7 %/% 2를 썼습니다).

All five lines tried to write the same expressions 7 / 2, -7 / 2 and -7 % 2, yet results split. In C, C++ and Java integer division truncates toward zero (-3) and the remainder takes the sign of the first operand (-1). Python's // floors (-4) and the remainder takes the sign of the second operand (1), while / is always real division (3.5). R's / is real too; integer division is %/% and remainder %% (below only Python and R use -7 // 2 and -7 %/% 2).

C

#include <stdio.h>
int main(void) {
    printf("%d %d %d\n", 7 / 2, -7 / 2, -7 % 2);
    return 0;
}
3 -3 -1

C++

#include <iostream>
int main() {
    std::cout << 7 / 2 << " " << -7 / 2 << " " << -7 % 2 << "\n";
}
3 -3 -1

Java

public class Main {
    public static void main(String[] args) {
        System.out.println((7 / 2) + " " + (-7 / 2) + " " + (-7 % 2));
    }
}
3 -3 -1

R

cat(paste(7 / 2, -7 %/% 2, -7 %% 2), "\n", sep = "")
3.5 -4 1

Python

print(7 / 2, -7 // 2, -7 % 2)
3.5 -4 1

In reality they are mixed. For example this site's grid tools (pycim, pandapower for load flow) are Python, the numeric libraries beneath are C/C++/Fortran, R is handy when analysing the same data statistically, and a Java backend may take it when it goes out as a service. More important than picking one language is the ability to join tools that fit each job, and the joints are REST APIs, files and databases.

  1. 처음이라면 Python 으로 프로그래밍 감각을 잡고,
  2. If you are new, build your sense of programming with Python,
  3. 메모리와 컴퓨터가 실제로 어떻게 움직이는지 알고 싶다면 C 로 한 번 내려가 보고,
  4. go down once to C if you want to know how memory and the machine really work,
  5. 큰 시스템을 다루게 되면 Java 나 C++ 를, 분석이 주업이면 R(또는 Python)을 깊이 파세요.
  6. dig into Java or C++ for big systems, or R (or Python) if analysis is your job.
