직접 질의하고, 그래프로 보기Query it, see it as a graph

전력망 데이터를 브라우저 안에서 다룹니다. 서버 없이 Oxigraph(WebAssembly SPARQL 엔진)가 RDF를 메모리에 올려 질의를 실행합니다.

Work with grid data right in your browser. No server: Oxigraph (a WebAssembly SPARQL engine) loads the RDF into memory and runs your queries.

참고: SPARQL은 RDF 질의의 W3C 표준이라 이 실습에서 다룹니다. 이 사이트는 현업에서 가장 많이 쓰는 Neo4j 중심으로 가므로, 그래프 DB 질의는 Cypher를 기본으로 합니다.

Note: SPARQL is the W3C standard for RDF queries, so this lab covers it. The site is otherwise Neo4j-centred, the most widely used graph database, so graph queries default to Cypher.

SPARQL 실습SPARQL playground

예제 질의를 고르거나 직접 고쳐서 실행하세요 (Ctrl/⌘ + Enter). cim: · rdf: · rdfs: · ex: 접두어는 자동으로 붙습니다. 결과의 IRI를 누르면 아래 그래프에서 해당 노드로 이동합니다.

Pick a preset or edit and run (Ctrl/⌘ + Enter). Prefixes cim: · rdf: · rdfs: · ex: are added for you. Click an IRI in the results to jump to it in the graph.

💡 쉽게 말하면In plain words

데이터에게 질문을 던지는 곳입니다. 위의 예제 버튼을 누르면 질문이 채워지고, ▶ 실행을 누르면 답이 표로 나옵니다. 질문 속 ?name처럼 물음표가 붙은 단어가 빈칸이고, 표의 각 줄이 그 빈칸을 채운 답입니다. 처음이라면 "클래스별 개수"나 "도전성 설비 전체"부터 눌러 보세요.

This is where you ask the data questions. Click a preset to fill in a question, then ▶ Run to get answers as a table. Words with a question mark like ?name are blanks, and each row of the table is one way to fill them. New here? Try "Count by class" or "All conducting equipment" first.

지식 그래프Knowledge graph

위에서 고른 데이터를 그래프로 그립니다. 노드는 개체, 화살표는 CIM 관계(예: Equipment.EquipmentContainer)입니다. 이 그림도 SPARQL 질의 결과로 만든 것입니다. 단자(Terminal)를 끄면 설비와 노드를 점선으로 바로 잇습니다.

The selected dataset drawn as a graph: nodes are individuals, arrows are CIM relations (e.g. Equipment.EquipmentContainer). It is built from a SPARQL query too. With Terminals hidden, equipment links straight to nodes with dashed lines.

💡 쉽게 말하면In plain words

데이터를 마인드맵처럼 그린 그림입니다. 점 하나가 사물(변전소, 차단기, 노드 등), 화살표가 "~에 속한다", "~에 연결된다" 같은 관계입니다. 색은 종류이고, 점을 누르면 그 사물에 대해 적힌 문장(트리플)이 모두 나옵니다. 마우스 휠로 확대해 보세요.

The data drawn like a mind map: each dot is a thing (substation, breaker, node…), each arrow a relationship such as "belongs to" or "connects to". Colour shows the kind; click a dot to see every sentence (triple) about it. Scroll to zoom.
